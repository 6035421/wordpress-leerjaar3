# 🐳 WordPress Docker Project

Een schoolproject waarbij WordPress wordt opgezet met behulp van Docker en Docker Compose.

---

## 📁 Projectstructuur

```
project/
├── docker-compose.yml       # Docker Compose configuratiebestand
├── nexus-events             # Eigen gemaakte plugin
├── nexusgaming              # Eigen gemaakte thema
├── README.md                # Dit bestand
└── wordpress/               # ⚠️ LEGE MAP — zie uitleg hieronder
```

### ⚠️ Waarom is de `wordpress/` map leeg?

De `wordpress/` map is **bewust leeg** gelaten in deze repository.

De volledige WordPress-installatie (inclusief plug-ins, thema's en geüploade bestanden) is te groot om via GitHub te uploaden.
